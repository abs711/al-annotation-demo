What is real: tiles and class masks are BCSS pool images; the contiguous blobs are the run's own P93 entropy contours after thin-island removal; every Dice, region count and pixel percentage is the measured value for that protocol's run at epoch 8. What is reconstructed: the sparse pixel set is recovered by inverting the colormap of the saved entropy figure and taking the top 5% — it follows the real P95 rule but is not the original array.
